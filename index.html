Vai

Uma central digital para consultar o transporte local de Imaruí — sem precisar perguntar a ninguém.

Vai — plataforma independente de informação sobre transporte. Não substitui comunicados oficiais das empresas operadoras. Confira sempre os avisos oficiais em caso de alterações de última hora.

Aviso sobre o projeto

O Vai Imaruí é um projeto educacional independente, desenvolvido por estudantes no contexto do IFA, sem fins lucrativos e com finalidade exclusivamente informativa. Os nomes das empresas de transporte mencionados neste site são utilizados apenas para identificar os serviços, linhas e horários apresentados. A menção a essas empresas não implica parceria, patrocínio, autorização ou vínculo oficial. O projeto não representa as empresas citadas. Para confirmar informações sobre horários, tarifas e itinerários, recomendamos consultar diretamente os canais oficiais das respectivas empresas.
